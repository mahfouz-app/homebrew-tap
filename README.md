# Mahfouz Homebrew Tap

Homebrew packaging for [Mahfouz](https://github.com/mahfouz-app/app), a cross-platform
Markdown PKM, on macOS.

## Install

```sh
brew install --cask mahfouz-app/tap/mahfouz
```

Or tap first, then install:

```sh
brew tap mahfouz-app/tap
brew install --cask mahfouz
```

## What's in the tap

| Cask | Description | Platforms |
| --- | --- | --- |
| `mahfouz` | Cross-platform Markdown PKM | macOS (Apple Silicon) |

`brew info mahfouz-app/tap/mahfouz` shows the version currently offered.

## Supported platforms

- **macOS** — Apple Silicon (arm64) only. Intel Macs are not supported.

## Verifying releases

Homebrew checks the SHA-256 of the downloaded `.dmg` against the checksum pinned in the
cask, so a normal `brew install` is already verified.

The `mahfouz` repository is private, so its release assets aren't fetchable directly —
this tap mirrors each macOS release onto its own [Releases page](https://github.com/mahfouz-app/homebrew-tap/releases)
to give the cask a stable, publicly downloadable URL.

## Upgrading

```sh
brew update && brew upgrade mahfouz
```

`brew update` is the step that pulls new cask revisions into your local copy of the tap —
`brew upgrade` alone will not see a new release.

## Uninstalling

```sh
brew uninstall --cask mahfouz
brew untap mahfouz-app/tap   # optional, removes the tap itself
```

## Troubleshooting

**`Error: Cask 'mahfouz' is unavailable`**
The tap isn't installed, or your local copy is stale:

```sh
brew tap mahfouz-app/tap && brew update
```

**Checksum mismatch during install**
Your local tap clone is out of date relative to the published release. Run `brew update`
and retry.

## Contributing

`Casks/mahfouz.rb` is generated by the `publish-homebrew-cask` job in
[mahfouz-app/app](https://github.com/mahfouz-app/app)'s `release-build.yml` and rewritten
on every release. Pull requests that hand-edit `Casks/mahfouz.rb` will be overwritten by
the next release and cannot be merged.

- **Packaging problems** — install failures, a wrong architecture, a bad checksum — are
  in scope for this repository. Please open an issue here.
- **Bugs in the app itself** belong in [mahfouz-app/app](https://github.com/mahfouz-app/app).
